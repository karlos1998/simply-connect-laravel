# Contributing

Thank you for improving the Simply Connect Laravel SDK.

1. Open or reference a GitHub issue before implementation.
2. Keep API behavior aligned with the canonical OpenAPI contract in `modern-simply-connect-api`.
3. Add focused tests for every behavior change.
4. Run the complete local quality gate:

   ```bash
   composer check
   ```

5. Use an English conventional commit message.

Never add live API keys, real phone numbers or private SMS content to tests, fixtures, logs or issue reports.
